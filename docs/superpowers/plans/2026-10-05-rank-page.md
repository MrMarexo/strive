# Rank Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a rank "bestiary" page opened from the header's rank title, showing a 20×20 pixel sprite, lore and days spent for each of the 15 ranks, with unreached ranks locked.

**Architecture:** A new persisted `rankDays` map is credited inside the pure `settle()` and read through two selectors (`daysInRank`, `isUnlocked`). Navigation is hash-based: a tiny `useHash` hook plus a pure `parseRoute`, with no router library. `App` renders either the home screen or the new `RankPage`, and sprites and lore live in a static `ui/rankContent.ts`.

**Tech Stack:** Vite, React 19, TypeScript (strict), plain CSS, Vitest + jsdom + React Testing Library (existing).

**Spec:** `docs/superpowers/specs/2026-10-05-rank-page-design.md` (extends `docs/superpowers/specs/2026-10-04-strive-tracker-design.md`)

## Global Constraints

- No router or UI libraries; navigation uses `location.hash` only.
- Routes: `''` / `#` / `#/` → home; `#/ranks/<slug>` → rank page; anything else → home; unknown slug → current rank.
- `rankSlug(title)` = lowercase, runs of non-alphanumerics → `-`, trim leading/trailing `-`.
- A day `d` is credited to `getRank(points at start of d).current.title`; displayed days add +1 (today) for the current rank only.
- Unlocked = Beggar, or current rank, or `rankDays[title] > 0`.
- `rankDays` stays under the existing `strive:v1` key; it is migrated to `{}` when missing; its keys must be `RANKS` titles and its values integers ≥ 0.
- Colors: `#000`, `#B48CFF`, `#5A3F8C` only; font VT323; no glyphs outside VT323's Latin set (use text brackets `[<]` `[>]`, `*` instead of ◆).
- Sprites are 20×20 `string[]` maps of `#` / `.`.
- Work directly on `main`; commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; push to `origin main` after the final task.
- No manual browser testing (the user's real data lives in that browser's localStorage); verify with `npm test` and `npm run build`.

## Review Focus

1. **Refreshing or bookmarking the rank page** → reopens the same rank page, not home. Pinned in Task 4 (App renders the page from an initial hash).
2. **Midnight passes while the rank page is open** → settlement still runs and the days count goes up without leaving the page. Pinned in Task 4.
3. **Leaving the rank page** → its arrow/Escape key listeners are removed, so arrow keys on the home screen do nothing. Pinned in Task 3.
4. **Unknown or mistyped slug** (`#/ranks/emperor`) → shows the player's current rank instead of crashing or showing a blank page. Pinned in Task 4.
5. **Dropping below a rank you've reached** → that rank stays unlocked, with its days intact. Pinned in Task 1.

```ts
// Settled days in the rank, plus today if it's the current rank.
export function daysInRank(state: AppState, title: string): number {
  const days = state.rankDays[title] ?? 0;
  return title === getRank(state.points).current.title ? days + 1 : days;
}

export function isUnlocked(state: AppState, title: string): boolean {
  return (
    title === RANKS[0].title ||
    title === getRank(state.points).current.title ||
    (state.rankDays[title] ?? 0) > 0
  );
}
```

```ts
import { useEffect, useState } from 'react';

export type Route = { page: 'home' } | { page: 'rank'; slug: string };

export function parseRoute(hash: string): Route {
  const match = /^#\/ranks\/([^/]+)$/.exec(hash);
  return match ? { page: 'rank', slug: match[1] } : { page: 'home' };
}

export function useHash(): string {
  const [hash, setHash] = useState(() => window.location.hash);
  useEffect(() => {
    const onChange = () => setHash(window.location.hash);
    window.addEventListener('hashchange', onChange);
    return () => window.removeEventListener('hashchange', onChange);
  }, []);
  return hash;
}

export function navigate(hash: string): void {
  window.location.hash = hash;
}
```

- [ ] **Step 4: Implement `src/ui/RankPage.tsx`**

```tsx
import { useEffect } from 'react';
import { RANKS, getRank, rankSlug, type Rank } from '../domain/ranks';
import { daysInRank, isUnlocked } from '../domain/selectors';
import type { AppState } from '../domain/types';
import { PixelSprite } from './PixelSprite';
import { LOCKED_SPRITE, RANK_LORE, RANK_SPRITES } from './rankContent';

interface RankPageProps {
  state: AppState;
  rank: Rank;
  onNavigate: (hash: string) => void;
}

const HOME = '#/';
const rankHash = (rank: Rank) => `#/ranks/${rankSlug(rank.title)}`;

export function RankPage({ state, rank, onNavigate }: RankPageProps) {
  const index = RANKS.indexOf(rank);
  const prev = RANKS[index - 1];
  const next = RANKS[index + 1];
  const unlocked = isUnlocked(state, rank.title);
  const isCurrent = getRank(state.points).current === rank;
  const days = daysInRank(state, rank.title);
  const title = rank.title.toUpperCase();

  useEffect(() => {
    const onKey = (event: KeyboardEvent) => {
      if (event.key === 'ArrowLeft' && prev) onNavigate(rankHash(prev));
      if (event.key === 'ArrowRight' && next) onNavigate(rankHash(next));
      if (event.key === 'Escape') onNavigate(HOME);
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [prev, next, onNavigate]);

  return (
    <section className="rank-page" aria-label={`${rank.title} rank`}>
      <div className="rank-page-top">
        <button type="button" className="btn" onClick={() => onNavigate(HOME)}>
          [ &lt; BACK ]
        </button>
        <span className="meta">
          RANK {index + 1}/{RANKS.length}
        </span>
      </div>
      <div className="rank-page-art">
        <button
          type="button"
          className="btn"
          aria-label="Previous rank"
          disabled={!prev}
          onClick={() => prev && onNavigate(rankHash(prev))}
        >
          [&lt;]
        </button>
        <PixelSprite
          map={unlocked ? RANK_SPRITES[rank.title] : LOCKED_SPRITE}
          title={unlocked ? rank.title : 'Locked rank'}
          size={200}
          className={unlocked ? 'sprite' : 'sprite sprite-locked'}
        />
        <button
          type="button"
          className="btn"
          aria-label="Next rank"
          disabled={!next}
          onClick={() => next && onNavigate(rankHash(next))}
        >
          [&gt;]
        </button>
      </div>
      <h2 className="rank-page-title">{title}</h2>
      <p className="meta">{rank.min} PTS+</p>
      {unlocked ? (
        <>
          <p className="lore">{RANK_LORE[rank.title]}</p>
          <p className="rank-days">
            {days === 1 ? 'DAY' : 'DAYS'} AS {title}: {days}
          </p>
          {isCurrent && <p className="current-tag">* CURRENT RANK *</p>}
        </>
      ) : (
        <p className="lore">REACH {rank.min} PTS TO UNLOCK</p>
      )}
    </section>
  );
}
```
